## Academic Curriculum

The VNSGU BCA programme framework for **Artificial Intelligence and Data Analytics** describes study areas including:

- AI foundations, machine learning, neural networks, natural language processing, and computer vision
- Statistical analysis, data mining, and predictive modelling
- Programming for analytics with Python, R, and SQL
- Data management, visualisation, and big-data technologies such as Hadoop, Spark, and NoSQL
- Practical AI applications, problem-solving, data privacy, and responsible use of data

The published Semester 1–2 syllabus lists **Introduction to Artificial Intelligence**, **Computer Programming and Programming Methodology**, and **Data Processing and Analysis**.

- [VNSGU BCA (A.I. and Data Analytics) syllabus — Semesters 1 &amp; 2 (2024–25)](https://vnsgu.ac.in/uploads/syllabus/Syllabus%20%282024-2025%29/Computer%20Science/UG/BCA%20Artificial%20Intelligence%20%26%20Data%20Analytics%20%28Honours%29%20Sem%201%20%26%202%20Syllabus%20from%202024-25%20%28dt%2029-05-2024%29.pdf)
